# CommunityHub

White-label community management platform with AI-powered events, membership, and engagement.

## Features

- Event management with registration, payments, and waitlist
- Fraud-resistant member onboarding (OTP, referral, AI scoring)
- AI chatbot (bilingual), event recommendations, content generation
- Admin panel with dashboard, reports, communications
- Donations, volunteering, sponsorship
- PWA support, SEO optimized

## Tech Stack

Next.js 16 | TypeScript | Tailwind CSS | Supabase | Claude API | PayPal | PayNow

## Quick Start

1. Clone: `git clone https://github.com/kasi-tech/communityhub`
2. Install: `npm install`
3. Configure: `cp .env.local.example .env.local` (fill in values)
4. Run: `npm run dev`
5. Open: http://localhost:3000

## Testing

```bash
# Unit tests
npm run test

# Unit tests with coverage
npm run test:coverage

# E2E tests (starts dev server automatically)
npm run test:e2e
```
